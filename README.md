# Retail-Customer-Retention-Analytics
The project analyse customer churn and retention in walmart
Made a unified Power BI data model using Power Query to transform and integrate disparate customer demographics, transaction logs, loyalty metrics, and store performance data.
Developed DAX measures and calculated columns to track Churn, Customer Lifetime Value (CLV), and loyalty tier performance, delivering interactive dashboards that guided cross-channel retention strategies.
